Existing content is now separated into three YouTube-Studio-style sections:
- Videos
- Shorts
- Live

Live detection uses YouTube live metadata.
Shorts caveat: YouTube Data API does not expose a direct 'isShort' flag. This UI treats non-live content up to 3 minutes as a Short candidate. YouTube's own final Shorts classification can differ.
